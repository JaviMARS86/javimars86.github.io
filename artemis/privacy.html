Artemis Privacy Policy

Effective October 28, 2026.

Who uses Artemis

Artemis is a personal assistant built and used only by its developer, Javi Ibanez Matles. It is not offered to the public, and no one else's data is collected.

What data Artemis accesses

Google Calendar: Artemis reads events from my calendars. It can create and edit events only in the calendars it creates itself, and it cannot change any other calendar.

Gmail: Artemis can search and read my emails. It cannot send, delete, or change any email.

Artemis also reads my course deadlines from my university's Blackboard calendar feed and WeBWorK.

How the data is used

This data is used only to answer my questions and keep me organized, for example to tell me what is due or whether I have time for something.

To answer, parts of this data are sent to Anthropic's Claude AI service. Anthropic processes it under its own privacy policy.

Where the data is stored

Login tokens are stored only on my own computer. Artemis may save short notes, such as a reminder that an assignment was submitted, in files on my computer and in a private GitHub repository that only I can access. Emails and calendar events are not copied in full or stored permanently.

What Artemis never does

Artemis never sells or shares data with anyone, and never uses it for advertising.

Artemis's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the third-party connections page of the Google Account (myaccount.google.com/permissions). Deleting Artemis's token file on my computer also ends its access.
